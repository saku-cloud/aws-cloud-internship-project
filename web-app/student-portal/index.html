Security & IAM

Security controls implemented using AWS identity, network and storage security practices.

Restricted SSH

SSH access is restricted to the administrator's current public IP address.

✓

IAM Role for EC2

EC2 accesses S3 through an IAM role instead of storing AWS access keys on the server.

✓

Private S3 Bucket

✓

Root MFA
